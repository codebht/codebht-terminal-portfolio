# codebht_ Terminal Portfolio

Static HTML/CSS portfolio. No Node.js, npm or build command is required.

## GitHub → Vercel
1. Create a GitHub repository.
2. Upload `index.html`, `style.css` and `vercel.json`.
3. In Vercel, import that GitHub repository.
4. Framework preset: Other.
5. Leave Build Command empty.
6. Output Directory: `.`
7. Deploy.
